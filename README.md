## About

专注于把 AI 能力融入软件测试与工程效率，持续探索接口自动化、E2E 测试、RAG 知识检索和多 Agent 测试编排。

当前公开项目主要围绕三个方向展开：

- 用 Python、Pytest 和 YAML 数据驱动构建可维护的 API 自动化测试框架
- 用 Playwright、POM 和 Claude Code 组织 Web E2E 测试与测试设计流程
- 用 RAG 和 AI 工具提升测试用例生成、知识复用和多平台测试能力
